# A2A Agent — Real Estate Capitale

Agent IA spécialisé dans l'immobilier — recherche de biens, estimation, conseil, prise de rendez-vous et génération de documents.

## Agent Card

Fetch the A2A Agent Card:

    GET /.well-known/agent-card.json

## Endpoint

POST `https://realestatecapitale.ma/a2a` with JSON-RPC 2.0 body.

## Skills

- property-search — Recherche de biens immobiliers
- property-valuation — Estimation immobilière
- real-estate-advice — Conseil immobilier
- appointment-booking — Prise de rendez-vous
- document-generation — Génération de documents
